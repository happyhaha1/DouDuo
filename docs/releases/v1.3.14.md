# DouDuo 1.3.14

1.3.13（91）之后的性能修复与折叠屏布局修正。包为**未签名 IPA**，需要自行签名安装。

## 修复 1.3.13 滑动卡顿
- **正常速度（1x）改回系统原生声音**：1.3.13 合入的「倍速不断声」独立音频引擎会在主线程上解码声音，并在预加载时为后面几条视频提前解码，滑动时容易掉帧。现在只有把播放速度设成 0.75 / 1.25 / 1.5 / 2 倍时才启用该引擎；1x 下不再解码，也不再预热音频。
- 在「更多」里切换速度时，当前视频会就地切换声音通路，从当前位置接着放，不用滑走再回来。
- **简洁 / 极简模式的进度环不再拖累整屏**：进度环每 0.25 秒更新一次，1.3.13 里这个更新会让整个首页一起重新计算；现在只重画进度环本身。

## 半折叠布局
- 推荐页半折叠时，视频和评论按真实折痕位置切分（与直播分屏同一套几何），折痕两侧都不压内容；书本姿态下评论区不再被右上角状态栏挤得偏左。

## 验证与仍需确认的边界
- 模拟器：1x 下 2 次绑定全部走原生声音、1.5x 下全部走独立引擎；简洁模式与默认模式均正常起播。
- 半折叠布局已在 iPhone Duo 真机上看过竖屏与横屏两种姿态。
- 模拟器 CPU 采样波动较大，**本版未能用数据证明真机上的流畅度提升幅度**，请升级后反馈。
- `test_live_categories.py` 仍失败，该问题在本版之前已存在。

## 本地构建 93：播放与个性化

入口为「更多 → 个性化与播放」。保留三档界面、清屏、长按倍速和侧滑手势；本页恢复默认不清理账号、视频缓存，也不改手动静音和倍速。

- 五组独立透明度：顶部入口、侧边操作、作者、描述与配乐、进度，范围 10%–100%，默认 100%；清屏时叠加原有半透明效果，退出按钮始终可见。
- 默认仅蜂窝、热点及低数据模式省流；可改始终开启或关闭。网络首次回调前保守省流，开启后取消在飞的自动缓存，仅预载下一条并缩短前向缓冲；保留磁盘缓存与手动保存。
- 直播默认封面浏览，进入房间才拉流，退出后停止流、聊天与邻居预热；关闭封面浏览仍受省流策略约束。
- 保留接口返回的真实多画质地址；自动档在省流时选低码率，也可手动选择最高、低码率或具体档位。换源精确恢复进度并保留暂停；过期回调不能恢复已离开的页面，失败可重试。
- 实际解码分辨率与方向锁放在「更多」菜单，不再在画面上常驻角标或悬浮按钮；锁定不改折痕布局。部分系统或 iPad 多任务环境可能不接受应用的旋转请求。
- 启动静音默认关闭；支持本次解除与前台音量变化解除，手动静音独立保留。系统没有报告音量变化时（例如极值音量键），无法可靠判断按键。
- 弹幕字号 10–28pt、自动或 1–10 行、透明度及清屏显示可调；字号参与宽度、行高和缓存计算，大字号自动减少行数，保留上方三分之一、密度和去重限制。
- 配乐、发布时间可分别隐藏，AI 声明独立保留。推荐时间筛选可按天或日历月，默认关闭并保留无时间视频，只调整后续推荐。
