# DouDuo 1.3.12

包含关注与直播入口修正、播放手势与长按清屏调整，以及爱思助手签名失败的排查说明。包为**未签名 IPA**，需要自行签名安装。

## 关注与直播入口
- **关注页只放关注作品**：不再在顶部挂一排「直播中」头像，刷关注不再被直播入口打断。
- **直播页不再重复挂关注头像条**：看直播时页面更干净；关注主播的开播列表统一走直播页的「我的关注」按钮，点开即是完整列表。

## 安装：爱思助手签名失败先登录一次 iCloud
- 很多人卡在「签名失败 / 验证失败 / 无法请求签名」，原因是准备签名的 Apple ID 从未在该设备上登录过 iCloud。
- 处理办法：在手机 Safari 打开 [icloud.com](https://www.icloud.com)，用**同一个 Apple ID** 登录一次，按提示同意条款、完成双重认证，然后回爱思助手重新「开始签名」。
- README 的「方式一：爱思助手」教程已补上这条提示，位于「添加 Apple ID」之后。

## 沿用 1.3.11 的能力
- 消息中心主从导航、聊天分享视频跳原生播放、评论通知回复与配图、聊天黑色画布与窄屏遮挡修复。
- 右侧操作栏间距 12/16pt、展开时按系统栏光学校正。
- 合入社区 PR #8：分享浮层暂停不再被「后台播放」绕过、直播切台恢复、VLC 渲染恢复；并取 PR #5 指出的手动暂停与锁屏倍速两处小修。

## 播放手势与清屏

- 双击视频改为打开评论区；点赞仍通过右侧点赞按钮操作。
- 长按视频画面或视频上的点赞、评论等按钮可触发 2 倍速，触发时提供轻震反馈。
- 按住时隐藏标题、操作栏、顶栏、状态栏和进度条，只保留倍速提示；松手恢复控件。
- 长按识别与点击互斥，修复短暂加速后松手误触暂停，也避免长按按钮后顺带触发按钮操作。
- 横滑跳转进度仅在底部进度条生效；保留长按下滑锁定本条倍速、上滑取消。
- 右侧「更多」下方新增清屏按钮：点击后隐藏操作栏、顶栏和状态栏，作者、日期、文案、音乐及进度条保持 50% 不透明度，进度条仍可拖动。保留淡显的退出按钮，翻页延续清屏状态。
- Duo 展开宽屏打开右侧评论栏后，可在视频或评论区域向右滑收起；左滑、评论上下滚动和底部进度条拖动不会触发关闭。半折叠的常驻评论保持原有布局。
