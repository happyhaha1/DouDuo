# DouDuo 1.3.15

1.3.14（92）之后的一组体验修复（来自 issue #4、#15、#16 的反馈），并合入社区 PR #17（Duo 经典布局）与 #23（翻页更利落）。包为**未签名 IPA**，需要自行签名安装。

## 非 Duo 机型顶栏点不到（#16）
- 默认模式的顶栏原本按 iPhone Duo 外屏往上推了 80pt 贴顶，在其他 iPhone（含 LiveContainer 打开）上会被推进状态栏和灵动岛里，点不到。
- 现在只有 Duo 保持原来的贴顶位置；其他机型的顶栏放在状态栏下沿，倍速角标也跟着下移，不再和顶栏重叠。

## 长按加速（#4 后续反馈）
- **触发更快**：长按从 0.5 秒改为 0.3 秒，更跟手。
- **简洁 / 极简模式**：长按加速时右侧整列（圆形入口、点赞评论收藏、更多）和作者标题一起淡出，与默认模式一致。
- 右侧圆形入口保持原设计：长按只显示作者和标题（极简模式），不触发加速；轻点打开菜单。
- **简洁 / 极简模式底部留白减少**：这两种模式没有底部进度条（进度画在入口外圈），作者和标题整体下移，不再给进度条留空。

## 半折叠时竖屏短视频变少
- 1.3.14 把「现在是横着看还是竖着看」改成按半折叠后视频那一块的形状来判断。竖着拿的桌面半折叠，视频块接近正方形（约 466×455）甚至偏宽，被判成「横着看」，推荐流按「横屏时只放横屏内容」只排横屏视频，竖屏短视频几乎刷不到。
- 现在恢复 1.3.13 的判断口径：按整屏形状判断横竖，半折叠的分屏布局本身不变。

## 评论栏与系统竖栏的间距（#15）
- 评论栏在右侧时（书本半折叠 / 内屏展开），按系统竖栏（时间、信号）的实际宽度收窄评论栏，不再整块往左平移；评论标题行也不再额外让出 88pt，右侧空隙明显变小。
- 半折叠按真实折痕切分（1.3.14 起）保持不变。

## 可选「经典」布局（合入 PR #17，感谢 @zenghongjvn）
- 「更多 → 界面」新增 **经典**：系统 Dock（我的 / 私信 / 首页）、右侧互动胶囊、清屏按钮、双指捏合切换铺满、长按左右两侧加速 / 中间打开设置面板、新的分享与评论面板、左滑进作者页（内屏左右并排）。
- **默认不开启**，不选就和以前一样；仅在 iOS 27.1 及以上显示该选项。
- 合入时的调整：版本号沿用本版；半折叠选片和评论栏让开系统竖栏沿用本版修复；长按时长用本版的 0.3 秒，同时采纳 PR 的「手指一拖动就取消长按」，上下滑不再误触倍速；经典布局左上角「更多」三个点加上阴影，亮色画面上也能看清。
- 最低系统要求随之提高到 **iOS 26.0**（iPhone Duo 出厂即 iOS 26）。

## 上下翻页更利落（合入 PR #23，感谢 @AppleLiang96，关联 #22）
- 松手后页面滑到位的动画从系统默认约 0.43 秒缩短到约 0.1 秒，连续刷更跟手。只改这段动画，翻到哪一条、加载和播放都不变。
- 作用于推荐、关注，以及从作者主页 / 喜欢 / 收藏点进去的视频列表；直播、评论区、图集不受影响。
- 固定为最快一档，**不提供设置菜单**；系统开启「减少动态效果」时自动使用系统默认分页。

## 本地构建 102：清屏按钮长在自己的容器里，进出不位移

- 构建 101 把按钮交给系统工具栏，位置由 iOS 决定：折叠外屏上圆形模块入口 `(393,174)` 正好压在眼睛 `(395,180)` 上，展开内屏与折叠时的容器高度也不一样，所以按钮被遮住、两屏不一致。

## 本地构建 110：经典布局不再把互动胶囊塞进系统工具栏，竖屏顶栏回到一行

- 规范依据（Apple「Designing for iPhone Duo」与 SwiftUI `ReservedRegion` 文档）：竖向工具栏的项目按 Dynamic Island → 状态栏 → 工具栏 → 标签栏自上而下排列，溢出默认自下而上折叠；**自定义视图不会被纵向呈现**，只会被折进系统溢出菜单；`ellipsis` 符号保留给系统溢出菜单；内屏竖屏保留标准的横向顶栏 / 底栏。
- 根因：互动胶囊（自绘 `VStack`）放在 `ToolbarItem(placement: .bottomBar)` 里，系统在纵向栏中无法纵向呈现它，于是折成 `BottomOverflowBarButtonItem`——就是我们看到的「眼睛下面的三个点」。把槽高从 391 压到 262 无效，因为问题不是高度而是「自定义视图不能纵向呈现」。竖屏那一行被压下，是因为经典页顶栏按 `safeAreaInsets.top` 定位，而导航栏又占了 58pt，两套 chrome 叠在一起。
- 处理（`DouDuo/DYNavigationDock.swift`）：工具栏里只留清屏眼睛（`DYCleanScreenButton`，唯一的稳定锚点）；新增 `@MainActor final class DYToolbarAnchor`，由 `DYToolbarFrameReader` 把眼睛在窗口里的矩形写进单例；删除 `DYVideoToolbarActions`、`DYActiveVideoActionsKey`、`hidesActions`、`slotHeight` 与 `slotHeight` 那一套「隐内容不隐槽位」的补偿逻辑。
- 处理（`DouDuo/DouyinFeedView.swift`）：经典页自己画互动胶囊——`actionCapsule` 永远由页面渲染，纵向栏时用 `GeometryReader` 的 `.global` 原点换算，把胶囊顶边钉在眼睛底边 + 6pt（实测 `eye.maxY=166` → `capsule.minY=172`），横向栏时保持原来的垂直居中；新增 `duoRailHidden` 环境值替代旧的 `actions == nil` 语义（评论面板 / 直播 / 作者页占用时收整列）。顶栏 `headerTopInset` 改为只按状态栏高度（`max(statusBarFrame.height, 8)`）。
